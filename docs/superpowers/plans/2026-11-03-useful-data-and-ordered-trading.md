# План: полезные данные для модели и торговля без хаоса

> **Для исполнителей:** выполнять задачи по порядку, каждую через TDD (`superpowers:test-driven-development`), перед заявлением о готовности проходить `superpowers:verification-before-completion`. Шаги отмечаются `- [ ]`.

**Цель:** прекратить торговлю по сигналам без преимущества, начать проверяемую бумажную стратегию и построить обучение, в котором модель отвечает на вопрос, способный окупить издержки.

**Подход:** сначала останавливаем вред и собираем честный эталон, затем на длинной дневной истории проверяем, есть ли что предсказывать. Модель появляется в торговле только после того, как обгонит простое правило на данных, которых не видела.

**Стек:** Python 3.11, SQLite, scikit-learn, T-Bank Invest API, pytest.

**Основание:** ревизия от 2026-11-03 (память проекта `model-research-findings-2026-10-30`, коммит `94e32da`).

## Глобальные ограничения

- Код только локально, версия в `app/version.py`, коммит `vX.Y.Z Описание` на русском, на сервер только через git.
- Запись в рабочую БД и `.env` только после подтверждения пользователя, бэкапа в `backups/` и пробного прогона.
- `ml_enforce=1` и `ml_auto_tune=1` не включать без отдельного решения пользователя.
- Издержки в расчётах: 0,05% комиссии за сторону плюс половина спреда 0,011%.
- Прибыльность не обещать: метрики это итог в деньгах, доля плюсовых недель и худшая просадка относительно эталона.

## На что смотреть при проверке

1. Бумага без свежей цены в момент ребаланса: неделя не считается исполненной, попытка повторяется.
2. Перезапуск бота во время недели: повторного ребаланса нет, счёт сохраняется.
3. Рынок ниже средней: счёт уходит в кеш, а не держит прошлые бумаги.
4. Новая бумага с короткой историей не ломает расчёт импульса.
5. Закрытые входы не мешают сопровождению открытых позиций и виртуальным сделкам.

### Задача 4. Модель ранжирования (только если задача 3 нашла запас над издержками)

**Постановка:** не «сработает ли сделка», а «какая бумага обгонит рынок за следующие N дней».

- **Единица данных:** бумага в день. Больше никаких сотен коррелированных минутных эпизодов.
- **Цель:** доходность за N дней минус доходность рынка: убирает направление рынка, которое модель и выучивала раньше.
- **Признаки:** только из дневных свечей, одинаково считаемые в истории и в реальном времени: импульс 5/20/60 дней к рынку, волатильность, объём к среднему, ночной гэп, положение в диапазоне.
- **Эталоны, которые нужно обогнать:** импульс из задачи 2, случайный выбор, купить и держать.
- **Проверка:** скользящее окно по времени с зазором не меньше N дней, итог в деньгах после издержек, блочный бутстрап по неделям. Последний год данных не смотреть до финального прогона.
- **Включение:** сначала отдельный бумажный счёт рядом с правилом задачи 2, в торговлю только по решению пользователя.
