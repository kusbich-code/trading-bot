# План: дашборд показывает то, что бот делает на самом деле

> **Для исполнителей:** задачи по порядку, через TDD (`superpowers:test-driven-development`), перед заявлением о готовности `superpowers:verification-before-completion`. Шаги отмечаются `- [x]`.

**Цель:** по дашборду сразу видно, какая стратегия идёт, на чём, в каком режиме и с каким результатом. Ничто не выдаёт бумажный счёт за реальные сделки и старый контур акций за действующую стратегию.

**Подход:** новая вкладка «Стратегия» по умолчанию, полоса режима на всех вкладках и честные подписи старых вкладок. Логика расчётов в отдельном модуле с тестами, `webapp.py` только отдаёт данные.

**Стек:** FastAPI, vanilla JS, Plotly, pytest.

## Глобальные ограничения

- Комментарии, подписи и коммиты на русском, версия в `app/version.py`, на сервер только через git.
- Дашборд ничего не торгует и не пишет в БД: новый API только читает. Цены запрашиваются у брокера только на чтение.
- Правила бумажных счетов на время проверки не меняются. Параметры стратегии в интерфейсе берутся из кода, а не дублируются.
- Перезапуск сервиса `dashboard` требует sudo-пароль владельца: без него новая версия не покажется.

## На что смотреть при проверке

1. Счёт ещё не открыт: вкладка объясняет, когда будет первый ребаланс, а не показывает нули как результат.
2. Праздник: следующий ребаланс не назначается на нерабочий день.
3. Брокер не отдал цены: показывается значение на момент ребаланса с подписью, страница не падает.
4. Шорт: прибыль при падении цены, сторона подписана текстом, а не только цветом.
5. Узкий экран: нет горизонтальной прокрутки страницы.
