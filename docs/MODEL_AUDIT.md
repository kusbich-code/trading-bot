# Аудит модели торговли, 2026-10-21 (прод v5.8.9)

Метод: агент-аудитор на копии БД и копии кода (прод только на чтение), синтетические данные с известными ответами, ручная сверка расчётов. Из 101 функции: OK 67, SUSPECT 21, FAIL 10, N/T 3 (Telegram-функции). Живых ML-моделей нет (`ml_models` = 0), ML-фильтр пока ничего не блокирует. Контекст модели: [MODEL_OVERVIEW.md](MODEL_OVERVIEW.md), список функций: [MODEL_FUNCTIONS.md](MODEL_FUNCTIONS.md).
