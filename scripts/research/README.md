# Разовые исследовательские скрипты (ноябрь 2026)

Рабочие скрипты, которыми получены выводы планов из `docs/superpowers/plans/`. Они читают данные из текущей папки и подключают
друг друга через `exec`, поэтому запускать их нужно из папки с данными, куда скопированы и сами скрипты. Рабочую БД и брокера не трогают,
кроме загрузчиков: те только читают данные брокера и запускаются на сервере через `python -`.

Данные лежат в `data/research/` (не в git): `daily.jsonl`, `full.jsonl`, `extra.jsonl`, `hours.jsonl`, `npz/`.

| Скрипт | Что считает |
|---|---|
| `fetch3.py` | загрузка: секторы, даты дивидендов, отчётность, дневные свечи фьючерсов |
| `make_fut_list.py`, `fetch_hours_head.py` | загрузка: часовые свечи самых ликвидных фьючерсов |
| `load.py`, `bt.py` | минутные свечи 12 бумаг и движок бэктеста на них |
| `r9.py` | вето модели на минутных сделках |
| `r10.py` | гипотезы H1–H7, H9, H10: отбор акций и плечо |
| `r12.py`, `r13.py` | H8: тренд по фьючерсам, аудит и закрытый год |
| `r14.py` | H11: таймфреймы и их сочетания на акциях |
| `r16.py` | H12: таймфреймы на фьючерсах, с контролем сходимости с дневным движком |
